# Study Computer Graphics

A basic CMake project for studying computer graphics.

## Building

```bash
cmake .
cmake --build .
```

## Running

```bash
./Debug/StudyComputerGraphics.exe
```

## Requirements

- CMake 3.10 or higher
- C++17 compatible compiler (MSVC, GCC, Clang)

## Project Structure

- `CMakeLists.txt`: CMake configuration
- `src/main.cpp`: Main entry point
